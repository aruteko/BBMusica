# 変更履歴

BBMusica の変更履歴を記載する．
BBPlayer 2.8.0 までの履歴は，[CHANGELOG.BBPlayer.md](./CHANGELOG.BBPlayer.md) を参照．

## [1.0.0] - 2026-11-16

BBPlayer を基にした最初のリリース．

### 追加

- 日本語および中国語の表示に対応（端末の言語に応じて切り替え，設定からも変更可能）
- Bilibili にログインしなくても，検索，再生および投稿者ページを利用可能に
- ホーム画面にステーションの先頭曲を大きく表示し，選択するとその曲からステーションを開始
- 検索履歴を，検索欄を選択して未入力の間のみ表示
- ライブラリを2列のグリッド表示に変更し，プレイリストのサムネイルを曲数に応じて分割
- プレーヤー画面を横にスワイプして MV を表示
- イコライザー
- ハートによるいいね（取り消しも可能）
- Bilibili のテーマ色をアプリ全体の配色へ反映
- 背景色と文字色を白と黒に統一

### 変更

- アプリ名，パッケージ名，アイコンおよび署名鍵を BBMusica 独自のものに変更
- 元の開発者が運用するサーバー（更新確認，共有プレイリスト，利用状況の計測，寄付ページ）との通信を全て廃止
- アカウントおよびクラウド共有機能を廃止
