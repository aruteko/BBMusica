# 変更履歴

BBMusica の変更を、ここに記録します。
BBPlayer 2.8.0 までの履歴は、[CHANGELOG.BBPlayer.md](./CHANGELOG.BBPlayer.md) にあります。

## [1.0.0] - 2026-11-16

BBPlayer をもとにした、最初のリリース。

### 追加

- 日本語 / 中国語の画面（端末の言語に合わせる。設定で切り替え）
- Bilibili にログインしなくても、検索、再生、投稿者のページを使える
- ホームに、ステーションの先頭の曲を大きく表示。押すと、その曲からステーションを始める
- 検索履歴は、検索欄をタップして未入力のときだけ表示
- ライブラリを2列のグリッドに。プレイリストのサムネイルは、曲数に合わせて分割
- プレーヤーを横にスワイプして、MV を見る
- イコライザー
- ハートでいいね。取り消しもできる
- Bilibili のテーマ色を、アプリ全体の配色に反映
- 背景と文字を、はっきりした白・黒に

### 変更

- アプリ名、パッケージ名、アイコン、署名鍵を、BBMusica 独自のものに
- 元の作者のサーバー（更新の確認、共有プレイリスト、計測、寄付のページ）への通信を、すべてなくした
- アカウントとクラウド共有の機能を、なくした
